# Ten-Acre Community Plan: project status page

A plain-language, week-by-week plan and live progress page for the Mitacs Accelerate project **IT53891, "Generative Master-Planning and View-Value Studio for Indigenous On-Reserve Community Development"**. It is run by Gursahib Singh (Thompson Rivers University) with Sanctum Metals Inc., under the supervision of Professor Kevin O'Neil.

It is written for Neil Leonard (Sanctum Metals Inc.) and Professor Kevin O'Neil.

- **Open the page:** `index.html` (or the GitHub Pages link).
- **Update progress:** edit `status.js` only. See [UPDATING.md](UPDATING.md).

This repository holds only the shareable plan and status. Project data, code and partner documents are kept elsewhere, in private.

This work was supported by Mitacs through the Mitacs Accelerate program.
